<h2 id="about">📌 About</h2>

<p>
A modern, performant personal developer portfolio built with Next.js 16, React 19, and TypeScript. Featuring smooth animations powered by Motion and an immersive WebGL background via OGL, this portfolio showcases projects, skills, and work experience with a clean, dark aesthetic.
</p>

Key Features:

=> <span style='font-weight:700;'>Hero Section</span>: Animated introduction with an interactive WebGL/OGL canvas background and social dock links.

=> <span style='font-weight:700;'>Projects Showcase</span>: Filterable project cards highlighting 6 full-stack, web, and mobile projects with live demo and GitHub links.

=> <span style='font-weight:700;'>Experience Timeline</span>: Work experience entries with role, company, and description.

=> <span style='font-weight:700;'>Skills Grid</span>: Visual skill tags covering the full stack — frontend, backend, databases, and mobile.

=> <span style='font-weight:700;'>Dock Navigation</span>: macOS-style floating dock with animated social and navigation links.

=> <span style='font-weight:700;'>Smooth Animations</span>: Page and section transitions powered by Motion (Framer Motion).

=> <span style='font-weight:700;'>WebGL Background</span>: Immersive animated canvas rendered with OGL.

=> <span style='font-weight:700;'>Fully Responsive</span>: Mobile-first layout that adapts seamlessly across all screen sizes.

<h2 id="started">🚀 Getting Started</h2>

<h3>Prerequisites</h3>

- [Node.js](https://nodejs.org) (v18 or higher recommended)
- [Git](https://git-scm.com/downloads)
- [npm](https://www.npmjs.com)

<h3>Cloning</h3>

```bash
git clone https://github.com/BekaAbate/portfolio.git
```

<h3>Installing & Running</h3>

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

<h3>Building for Production</h3>

```bash
npm run build
npm start
```
